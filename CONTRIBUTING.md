# Contributing to Mergington High Extra-Curricular Activities

Thank you for helping improve the sample school's activities website. This repository is a training exercise; do not add real student records, private data, or credentials.

## Development setup

1. Clone this repository and create a feature branch.
2. Install Python dependencies with `pip install -r requirements.txt`.
3. Launch the development server with `python src/app.py`.
4. Open http://localhost:8000 and validate changes using sample data.

## Making changes

1. Open an issue or reference an existing one.
2. Use a descriptive branch name, for example `art-gallery-feature` or `fix-chess-signup`.
3. Make the smallest useful change and test it locally.
4. Push the branch, open a pull request, and respond to review findings.

## Code style

- Follow PEP 8 for Python.
- Use clear, descriptive function and variable names.
- Add tests for new behavior and bugs.
- Keep comments accurate and avoid committing secrets.

## Need help or have ideas?

Check open issues first; add a reproducible bug report or feature proposal if none matches. Be respectful of other contributors and school community members.
