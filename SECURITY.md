# Security Policy — Mergington High Sample Activities Website

This is an educational demo. Do not commit real student records, access tokens, passwords, or confidential material.

## Reporting a vulnerability

Please use the repository's **Security → Report a vulnerability** option when private vulnerability reporting is available. Do not publicly disclose exploit details or student data in GitHub issues.

Include a concise description, minimum reproduction steps, impact, and relevant versions. Redact all personal data.

## Response process

The repository maintainer will triage reports, investigate validated findings, and coordinate fixes in the appropriate private reporting channel before making vulnerability details public. Response timelines are best-effort for this training project.

## Supported versions

Only the current default branch of this course repository is maintained for the duration of the exercise.
