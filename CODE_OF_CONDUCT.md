# Mergington High School Code of Conduct

## Our pledge

Contributors commit to respectful, inclusive, and harassment-free collaboration on this demonstration extracurricular activities project.

## Our standards

Expected behavior includes constructive technical feedback, welcoming language, respect for differing experiences, protecting private information, and addressing disagreements professionally.

Unacceptable behavior includes harassment, discriminatory insults, threats, personal attacks, impersonation, and publication of private student or contributor data.

## Maintainer responsibilities

Maintainers may edit, remove, or reject material that violates this code. Any response will be proportionate to the situation and will prioritize participant safety.

## Scope

This code applies in repository discussions, issues, pull requests, and public communications made on behalf of this project.

## Reporting and enforcement

For a conduct concern, contact a repository maintainer privately through an established, appropriate communication channel. Do not publicly disclose sensitive personal information in an issue or pull request. Reports should be reviewed fairly and confidentially.
